# Web 管理后台使用手册

管理后台访问路径为 `https://你的域名/admin/`，推荐使用当前稳定版 Chrome 或 Edge，屏幕宽度不低于 1024px。

## 登录与角色

- `platform_admin` 可切换学校并查看全平台数据，还可管理管理员账号。
- `school_admin` 的学校范围由平台管理员绑定，顶部学校选择器固定，接口也会再次校验权限。
- Token 过期后会返回登录页。共用设备不要勾选记住账号，操作完成后主动退出。

首次平台管理员由服务器运维人员在 API 容器中创建：

```bash
docker compose -f deploy/compose.yml --env-file deploy/.env run --rm --no-deps db-init \
  python /app/scripts/create_admin.py admin --role platform_admin --display-name "平台管理员"
```

创建学校管理员时重复传入 `--school-id` 可绑定多所学校：

```bash
docker compose -f deploy/compose.yml --env-file deploy/.env run --rm --no-deps db-init \
  python /app/scripts/create_admin.py school-admin --role school_admin \
  --school-id 1 --school-id 2 --display-name "学校管理员"
```

密码通过终端隐藏输入，不要写入命令行、文档或聊天记录。后续管理员可在“管理员管理”页面创建、禁用和重置密码。

## 学校与区域

在“学校管理”中新建学校并维护名称、编码、城市、地址和状态。进入学校详情后维护校区、食堂、商圈等区域。停用学校前先确认其店铺与用户是否需要迁移；学校数据不会因为停用而物理删除。

## 店铺管理

1. 在顶部选择目标学校。
2. 按区域、分类、状态或关键词筛选。
3. 新增或编辑店铺的食堂、位置、名称和图片。
4. 使用上架、隐藏或关闭控制展示状态；批量操作前核对所选学校和数量。

店铺图片必须是系统已托管到公开 MinIO bucket 的 URL。外部任意 URL 会被拒绝，以避免失效链接、隐私泄露和服务端请求伪造风险。

## 批量导入店铺

先在页面选择导入学校，再下载模板。模板不包含学校列，中文列名为：

| 列名 | 必填 | 说明 |
| --- | --- | --- |
| `食堂` | 是 | 对应目标学校内已有食堂/区域 |
| `店铺位置` | 是 | 楼层、档口或详细位置 |
| `店铺名称` | 是 | 店铺展示名称 |
| `店铺图片` | 否 | 系统已托管图片的完整 URL，不可嵌入图片 |

支持 CSV/XLSX。上传后必须先预校验，全部行通过后才能确认；任意一行失败时整批不写入。确认前重点核对目标学校、总行数、新增数和更新数。

## 用户管理

用户列表按学校、状态、昵称、`externalId` 和注册时间筛选。点击用户进入档案，可查看账号信息、收藏/吃过统计、全部评论和打卡，并直接执行：

- 启用或禁用账号；
- 修改所属学校；
- 永久或限时禁止评论；
- 永久或限时禁止上传图片；
- 恢复评论或图片上传权限。

限制操作必须填写明确原因。处理具体用户时优先从用户档案进入，可减少误选同名用户的风险。

## 评论与打卡照片治理

评论和打卡均可按学校、店铺、用户、状态和时间筛选，也可从用户档案固定到具体用户。隐藏或恢复前需要填写原因：

- 隐藏评论后，该评论不参与店铺评分和评论数统计。
- 隐藏照片后，普通用户不可见，管理员仍可在鉴权后查看。
- 所有操作均为软治理，可恢复，不物理删除原始记录。
- 批量操作时先确认学校、筛选条件和已选数量。

## 管理员与审计日志

## 通知与公告

在“通知公告”中选择通知或公告，填写标题、富文本正文和接收范围。平台管理员可选择全平台、学校或用户；学校管理员只能选择授权学校及其中用户。正文图片必须通过编辑器上传，站内跳转从预设页面中选择。

消息可以立即发布或指定未来时间，并可设置失效时间。发布确认会展示预计站内接收人数和已授权微信人数。消息生效前仍可编辑，生效后内容固定；需要停止展示时执行撤回。只有用户已经在设置页授权对应微信模板，且消息开启微信同步时，Worker 才会尝试发送订阅消息。

发布后应检查消息状态和发送统计。微信失败不会阻断站内消息，临时错误由 Worker 自动重试，授权失效时用户需要在小程序设置页重新授权。

只有 `platform_admin` 可进入“管理员管理”。学校管理员至少绑定一所学校；平台管理员不绑定学校。账号不再使用时应禁用，不要多人共用同一账号。

“审计日志”记录操作者、学校、操作、目标、原因、IP 和时间，可按条件筛选和导出。日志用于追责与排障，不允许在后台修改或删除。

## 常见问题

- 图片不显示：确认 URL 属于配置的 `MINIO_PUBLIC_URL`，对象存在，HTTPS 证书正常且没有浏览器混合内容错误。
- 看不到某学校：确认当前管理员角色和 `admin_user_schools` 绑定关系。
- 导入失败：下载最新模板，不要修改中文标题，不要粘贴图片对象，先处理预校验标出的行。
- 操作返回 409：通常是店铺 `version` 已变化，刷新数据后重新编辑，避免覆盖他人的更新。
- 操作返回 401/403：重新登录；若仍失败，由平台管理员检查账号状态和学校权限。
